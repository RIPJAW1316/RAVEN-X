# Raven-X UI design system

Graphite/navy surfaces, cool blue primary actions, restrained cyan focus
accents, and thin technical borders establish the command-center visual
language. Severity colors are limited to finding severity; presence uses a
separate online/stale/offline palette. IDs and digests use monospace styling.
Motion is subtle and honors `prefers-reduced-motion`; status always includes
text, not color alone. Cards use compact spacing and 8–12px radii.
